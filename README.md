# link-text-skill
智能视频转录系统 - 将视频/音频转换为中文文本记录，支持智能下载、智能分段、质量优化和主题分类

## 🚀 新功能：智能下载策略

### 智能下载机制

系统现在具备智能下载功能，能够根据视频链接类型自动选择最优的下载策略：

#### 1. **纯音频链接**
- 当视频链接提供纯音频流时（如B站的音频格式）
- 直接下载音频文件，避免下载不必要的视频
- 提高下载速度，节省带宽和存储空间

#### 2. **视频链接**
- 当视频链接只能提供视频文件时
- 下载完整的视频文件
- 自动提取音频轨道进行转录
- 适用于无法单独下载音频的视频平台

#### 3. **本地文件支持**
- 支持本地音频文件（mp3, wav, m4a, flac）
- 支持本地视频文件（mp4, avi, mkv, mov）
- 自动处理并转换为适合转录的音频格式

## 📋 使用方法

### 基础使用
```bash
# 智能转录（推荐）
{baseDir}/scripts/smart_transcribe.py <URL>

# 指定输出目录
{baseDir}/scripts/smart_transcribe.py <URL> D:/输出目录
```

### 高级选项
```bash
# 智能下载演示
{baseDir}/scripts/main_simplified.py https://www.bilibili.com/video/BV1xxx
```

## 🔧 工作原理

1. **链接分析**：自动识别URL类型，确定最优下载策略
2. **优先音频**：尝试仅下载音频流，避免视频文件
3. **备用方案**：如果无法单独下载音频，则下载视频并提取音频
4. **格式转换**：自动将下载的音频转换为标准WAV格式
5. **智能转录**：分段处理音频，生成结构化文本

## 📁 输出结构

```
translate/{video-id}/
├── task_info.json      # 任务信息（包含下载策略）
├── transcript.md       # 转录结果
├── audio/              # 音频文件
└── videos/             # 视频文件（仅在下载视频时存在）
```
