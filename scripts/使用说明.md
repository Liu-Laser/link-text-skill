# 脚本使用说明

## 📁 脚本文件说明

### 主要脚本

#### 1. `main_simplified.py` - 核心转录脚本
**功能**：完整的视频转录流程
**特点**：
- 下载视频/音频
- 转换音频格式
- 分段转录
- 智能断句
- 生成结构化输出

**使用方法**：
```bash
# 基础使用
python main_simplified.py <URL>

# 指定输出目录
python main_simplified.py <URL> D:/输出目录

# 示例
python main_simplified.py https://www.bilibili.com/video/BV1xxx
```

#### 2. `smart_transcribe.py` - 智能监控版本 ⭐推荐
**功能**：带监控的核心转录脚本
**特点**：
- 无超时限制（已修改）
- 自动检测并发任务
- 实时状态显示
- 自动重试机制

**使用方法**：
```bash
python smart_transcribe.py <URL>
python smart_transcribe.py <URL> D:/输出目录
```

#### 3. `monitor_transcription.py` - 任务监控器
**功能**：独立监控任务进度
**特点**：
- 静默等待5分钟
- 每5分钟检查一次
- 动态调整超时时间

**使用方法**：
```bash
# 需要先启动转录任务
python main_simplified.py <URL>
python monitor_transcription.py 任务目录路径
```

#### 4. `utils.py` - 工具函数库
**功能**：各种辅助函数
**内容**：
- 文本处理函数
- 格式转换函数
- 质量检查函数

#### 5. `install_requirements.py` - 依赖安装脚本
**功能**：自动安装所需依赖
**使用方法**：
```bash
python install_requirements.py
```

## 🚀 脚本选择建议

### 推荐使用顺序
1. **`smart_transcribe.py`** - 日常使用首选
   - 无超时限制
   - 自动检测任务冲突
   - 稳定可靠

2. **`main_simplified.py`** - 基础功能
   - 纯转录功能
   - 适合调试
   - 不带监控

3. **`monitor_transcription.py`** - 独立监控
   - 需要配合 main_simplified.py 使用
   - 适合长时间任务监控

## ⚙️ 配置说明

### 环境变量配置
在命令行中设置：
```bash
# 模型选择
export TRANSCRIBE_MODEL=large-v3  # 最高质量
export TRANSCRIBE_MODEL=medium    # 平衡
export TRANSCRIBE_MODEL=base      # 基础质量

# 输出目录
export TRANSCRIBE_OUTPUT_DIR=~/transcripts

# 语言设置
export TRANSCRIBE_LANGUAGE=zh
```

### 自动检测配置
系统会自动检测：
- CPU核心数
- 内存大小
- 磁盘空间
- 自动选择最佳模型

## 🔧 故障排除

### 常见错误
1. **找不到模块**
   ```bash
   python install_requirements.py
   ```

2. **FFmpeg未找到**
   - 下载并添加到系统PATH

3. **内存不足**
   - 使用 base 模型
   - 关闭其他程序

4. **网络问题**
   - 检查网络连接
   - 手动下载模型

### 调试技巧
- 使用 `main_simplified.py` 进行基础调试
- 查看 `task_info.json` 了解任务状态
- 检查 `audio/` 和 `videos/` 目录确认下载成功

## 💡 高级用法

### 批处理示例
```bash
#!/bin/bash
# batch_transcribe.sh

urls=(
    "https://www.bilibili.com/video/BV1xxx"
    "https://www.youtube.com/watch?v=xxx"
    "https://xxx"
)

for url in "${urls[@]}"; do
    echo "处理: $url"
    python smart_transcribe.py "$url"
    echo "完成: $url"
    echo "------------------"
done
```
